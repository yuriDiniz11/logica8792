# Lógica de programação em C.

Exercícios de aula, com um commit a cada exercício novo aprendido.

## Conteúdos praticados:
  - Laços (for, while, do/while): figuras com *, tabuleiro, pirâmide de Pascal, números primos e perfeitos, inversão de número, combinações de cadeado.
  - Vetores: soma, média, pares e ímpares, ordenação, remoção de elemento.
  - Matrizes 2D e 3D.
  - Funções, com arquivos .c e .h.
  - Condicionais: if/else e votação.
